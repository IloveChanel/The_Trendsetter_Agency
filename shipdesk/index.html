ShipDesk

A Windows desktop workspace for developers preparing and maintaining mobile app releases. Connect App Store Connect to inspect release versions, subscription prices, offer-code settings, and screenshot inventories. Link your local project to compare the subscription IDs in your code with Apple’s records, or connect Google Play to audit listing metadata. Use Screenshot Studio to compare release images, check dimensions against supported Apple presets, and export resized copies. Ask questions in plain English, review what the stores returned, and export a report with findings and next steps.

ShipDesk runs on your computer, with optional OpenAI or Gemini explanations using your own API key. These store consoles are complicated. ShipDesk helps you set up your apps and troubleshoot issues locally, without sending your project or credentials to a remote server.

What ShipDesk does

App Store Connect

List authorized apps, releases and attached build IDs, screenshot inventory by locale and device, and subscription offer configuration. Compare offer mode, active state and customer eligibility when troubleshooting redemption.

Google Play

Enter a short-lived OAuth access token with the Android Publisher scope. ShipDesk opens a temporary edit to read listing metadata, then deletes the edit without committing changes. Audit this package to check listing text.

Screenshot Studio

Compare two folders of PNG files by filename and SHA-256, display dimensions, and export the new folder as a ZIP. Check dimensions against supported Apple presets and export resized copies. Exact file comparison can flag encoding or metadata changes.

Local project comparison

Link your local project to compare the subscription IDs in your code with Apple’s records. Ask questions in plain English and review what the stores returned. Export a report with findings and next steps.

Your own AI

Optional OpenAI or Gemini explanations using your own API key. Everything runs locally on your computer. No remote processing of your store data or project files.

Windows setup

Extract the ZIP and double-click Setup.cmd. Installs Flet desktop dependencies into an existing Python. Pillow is required for resizing. OpenSSL is required for Apple connections. Desktop shortcut is created.
